# 사용자 매뉴얼

이 시스템을 쓰는 두 부류를 위한 안내서입니다.

- **1부: 원장님용** — 관리자 화면으로 매장을 운영하는 방법
- **2부: 고객 안내용** — 고객에게 예약 방법을 알려줄 때 그대로 쓸 수 있는 안내문

---

# 1부. 원장님용 매뉴얼

## 처음 한 번만 하는 설정

1. **관리자 화면 접속**: `내주소/admin` → 아이디 `admin`, 비밀번호는 배포 때 정한 것
   (휴대폰 브라우저에서 열고 "홈 화면에 추가" 해두면 앱처럼 쓸 수 있습니다)
2. **영업시간/휴무** (`/admin/settings`):
   - 매장 이름, 오픈/마감 시간, 예약 간격(기본 30분)
   - 정기 휴무 요일 체크 (예: 월요일)
   - 여름휴가 같은 특정일 휴무는 "지정 휴무일"에 날짜로 추가
   - **무료 취소 마감**(기본 24시간): 고객이 이 시간 안에 취소하면 "마감 후
     취소"로 표시됩니다. 매장 정책에 맞게 조정하세요.
3. **메뉴/가격** (`/admin/services`):
   - 처음 들어있는 컷/펌/염색/클리닉은 예시입니다. 실제 메뉴로 수정하세요.
   - **소요시간이 곧 예약 간격입니다.** 펌을 120분으로 두면 펌 예약이 잡힌 시간대
     120분이 자동으로 막힙니다. 실제 걸리는 시간보다 약간 여유 있게 잡는 것을 권장.
   - **추가금 조건**을 써두면 고객 화면에 "기장 추가 +1만원"처럼 표시됩니다.
     예약 후 가격 실랑이를 막는 장치이니 자세히 쓸수록 좋습니다.
   - 안 하는 메뉴는 삭제 대신 **"숨김"** 처리 (과거 기록 보존).

## 매일 하는 일

### 아침: 오늘 예약 확인
`/admin` 첫 화면이 오늘 예약 목록입니다. ◀▶로 날짜 이동.
각 예약에서 시술·시간·고객 연락처·요청사항·희망 스타일 사진(📷)을 확인하세요.

### 시술 전: 사진 확인
예약 카드의 **📷 사진** → 고객이 올려둔 "원하는 스타일" 사진이 있으면 여기 보입니다.
상담할 때 이 사진을 기준으로 대화하면 됩니다.

### 시술 후: 상태 처리 + 결과 기록
- **방문 완료** 버튼: 정상 시술 완료
- **노쇼** 버튼: 연락 없이 안 온 경우 (기록이 남아 상습 노쇼 파악 가능)
- **📷 사진 → 시술 결과**: 정면/측면/뒷면 3장 촬영해 저장하세요.
  - 휴대폰에서 파일 선택을 누르면 바로 카메라가 뜹니다.
  - **촬영 전 고객에게 꼭 동의를 받으세요.**
  - 다음 방문 때 "지난번 그대로"의 기준이 되고, 분쟁 예방 기록도 됩니다.

### 전화 예약이 오면
`/admin` → **+ 수기 예약** → 시술/날짜를 고르면 빈 시간만 나옵니다.
전화로 예약을 받아도 시스템에 넣어야 웹 예약과 겹치지 않습니다.

### 고객 문의(1:1 채팅) 응대
고객이 웹의 "카카오톡으로 원장님께 문의하기" 버튼이나 챗봇에서 상담을 요청하면
카카오톡 채널 1:1 채팅으로 들어옵니다. 휴대폰에 **"카카오톡 채널 관리자" 앱**을
설치해 두면 알림을 받고 바로 답장할 수 있습니다. (설정 방법은 배포가이드 참고)

## 알아두면 좋은 것

- **리마인드**: 예약 확정 즉시 / 전날 저녁 7시 / 당일 아침 9시에 알림이 기록됩니다.
  (현재는 서버 기록까지이며, 카카오 알림톡 실발송은 2차 연동 예정)
- **마감 후 취소 표시**: 취소 마감(기본 24시간) 이후 취소한 예약은 목록에
  ⚠️ 표시가 붙습니다. 반복되는 고객은 다음 예약 때 참고하세요.
- **고객이 올린 사진/예약 정보는 본인과 원장님만 볼 수 있습니다.** 링크를
  아는 사람이라도 예약번호+전화번호가 맞지 않으면 열리지 않습니다.

# 2부. 고객 안내용 (복사해서 채널 공지 등에 쓰세요)

## 예약하는 방법 💇

1. 카카오톡 채널에서 **"예약"** 이라고 보내면 예약 링크를 드려요.
   (또는 바로 접속: `내주소/booking`)
2. **시술 선택** — 가격과 소요시간, 추가금 기준이 미리 표시돼요.
3. **날짜/시간 선택** — 가능한 시간만 보여드려요.
4. 이름과 휴대폰 번호를 입력하면 끝!
   - 원하는 스타일이 있다면 **사진을 최대 3장** 올려주세요. 캡처 이미지도 좋아요.
     사진이 있으면 상담이 훨씬 정확해져요.
5. 완료 화면의 **예약번호 6자리**를 꼭 기억해 주세요.

## 예약 확인·변경·취소

- 예약 페이지 하단 **"내 예약 조회"** → 예약번호 + 휴대폰 번호 입력
- 시간 변경, 취소 모두 전화 없이 바로 처리돼요.
- **예약 시간 24시간 전까지는 무료로 변경·취소**할 수 있어요.
  그 이후 취소는 매장에 안내되며, 반복되면 예약이 어려울 수 있어요.

## 더 편하게 쓰려면: 간편 로그인

예약 페이지 상단 **"간편 로그인"** → 카카오 또는 네이버로 1초 로그인.
가입 절차가 따로 없고, 로그인해두면 **예약번호 없이도** 내 예약을 바로
확인·변경할 수 있어요. (로그인 없이도 모든 기능을 쓸 수 있습니다)

## 자주 묻는 질문

**Q. 예약번호를 잊어버렸어요.**
매장으로 연락 주시면 확인해 드려요. 간편 로그인을 해두시면 예약번호가 필요 없어요.

**Q. 올린 사진은 누가 보나요?**
원장님과 본인만 볼 수 있어요. 외부에 공개되지 않아요.

**Q. 늦을 것 같아요.**
1인샵 특성상 뒤 예약에 바로 영향이 갑니다. 미리 연락 주시면 가능한 범위에서
조정해 드려요. 많이 늦으시면 시술이 축소되거나 변경될 수 있어요.
