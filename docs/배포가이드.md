# 배포 절차 가이드

미용실 예약 시스템 + 카카오 챗봇 서버를 실제로 띄우는 절차입니다.
순서대로 따라 하면 됩니다. (소요 시간: 처음 하면 1~2시간)

---

## 0. 준비물 체크리스트

| 준비물 | 어디서 | 필수 여부 |
|---|---|---|
| Anthropic API 키 | https://console.anthropic.com | 필수 (챗봇 대화용) |
| 카카오 i 오픈빌더 계정 + 챗봇 + 카카오톡 채널 | https://i.kakao.com | 필수 (챗봇 연동) |
| 호스팅 계정 (Render 추천, Railway/Fly.io도 가능) | https://render.com | 필수 |
| 카카오 로그인 앱 키 | https://developers.kakao.com | 선택 (간편 로그인 쓸 때) |
| 네이버 로그인 앱 키 | https://developers.naver.com | 선택 (간편 로그인 쓸 때) |

## 1. 로컬에서 먼저 확인 (선택이지만 권장)

```bash
pip install -r requirements.txt
echo "ANTHROPIC_API_KEY=sk-ant-..." > .env
uvicorn main:app --host 0.0.0.0 --port 8000
```

- http://localhost:8000/booking → 예약 화면이 뜨는지
- http://localhost:8000/admin → 아이디 `admin`, 비밀번호 `changeme`로 들어가지는지

## 2. 호스팅에 배포 (Render 기준)

1. 이 저장소를 GitHub에 두고, Render에서 **New → Web Service** → 저장소 연결
2. 설정값:
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
3. **⚠️ 영구 디스크(Persistent Disk)를 꼭 추가하세요.**
   - 예약 DB(`booking.db`)와 사진(`photos/`)이 서버 디스크에 저장됩니다.
   - 디스크 없이 무료 티어로 돌리면 **재배포/재시작 때마다 예약과 사진이 전부
     사라집니다.** Render의 Disk를 `/data` 같은 경로로 마운트하고 아래 환경변수로
     경로를 지정하세요: `BOOKING_DB=/data/booking.db`, `PHOTO_DIR=/data/photos`
4. 배포가 끝나면 `https://내서비스.onrender.com` 형태의 공개 URL이 생깁니다.

## 3. 환경변수 설정 (Render의 Environment 탭)

| 변수 | 예시 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | `sk-ant-...` | **필수.** Claude API 키 |
| `ADMIN_PASSWORD` | (긴 랜덤 문자열) | **필수.** 관리자 화면 비밀번호. 기본값 `changeme`인 채로 운영 금지 |
| `BOOKING_BASE_URL` | `https://내서비스.onrender.com` | **필수.** 챗봇이 안내하는 예약 링크 주소 |
| `BOOKING_DB` | `/data/booking.db` | 예약 DB 경로 (영구 디스크 위로) |
| `PHOTO_DIR` | `/data/photos` | 사진 저장 폴더 (영구 디스크 위로) |
| `SESSION_SECRET` | (긴 랜덤 문자열) | 로그인 세션 서명 키. 미설정 시 재시작마다 로그인이 풀림 |
| `KAKAO_CLIENT_ID` / `KAKAO_CLIENT_SECRET` | | 선택. 카카오 간편 로그인 |
| `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET` | | 선택. 네이버 간편 로그인 |
| `CLAUDE_MODEL`, `SYSTEM_PROMPT` | | 선택. 챗봇 모델/말투 조정 |

랜덤 문자열 만들기: 터미널에서 `python -c "import secrets; print(secrets.token_hex(32))"`

## 4. 카카오 오픈빌더에 챗봇 웹훅 연결

1. https://i.kakao.com → 내 챗봇 → **스킬** 메뉴 → 새 스킬 만들기
2. URL에 `https://내서비스.onrender.com/kakao/webhook` 입력 후 저장
3. **시나리오 → 폴백 블록**(사용자 발화가 어떤 블록에도 안 걸릴 때)을 열고,
   응답을 **스킬데이터**로 바꾼 뒤 방금 만든 스킬을 선택
4. 우측 상단 **배포** 버튼 클릭
5. 카카오톡 채널에서 챗봇에게 말 걸어 확인:
   - 아무 말 → Claude가 답변
   - "예약할래요" → 예약 페이지 링크가 와야 정상

## 5. (선택) 간편 로그인 켜기

### 카카오
1. https://developers.kakao.com → 애플리케이션 추가
2. 앱 설정 → 플랫폼 → Web에 `https://내서비스.onrender.com` 등록
3. 제품 설정 → 카카오 로그인 **활성화**, Redirect URI에
   `https://내서비스.onrender.com/booking/login/kakao/callback` 등록
4. 동의항목에서 닉네임(프로필 정보) 설정
5. 앱 키 중 **REST API 키**를 `KAKAO_CLIENT_ID`로 설정
   (보안 탭에서 Client Secret 생성 시 `KAKAO_CLIENT_SECRET`도)

### 네이버
1. https://developers.naver.com → 애플리케이션 등록 → 사용 API: **네이버 로그인**
2. 제공 정보: 닉네임 선택
3. 서비스 URL: `https://내서비스.onrender.com`,
   Callback URL: `https://내서비스.onrender.com/booking/login/naver/callback`
4. Client ID/Secret을 `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET`으로 설정

키를 넣지 않은 제공자는 로그인 버튼이 자동으로 숨겨지므로, 하나만 먼저 켜도 됩니다.

## 6. 배포 후 점검 체크리스트

- [ ] `https://내서비스.onrender.com/` → `{"status": "ok"}` 응답
- [ ] `/booking` 에서 실제로 예약을 하나 넣어보기 (본인 번호로)
- [ ] `/booking/lookup` 에서 예약번호+전화번호로 조회/취소 되는지
- [ ] `/admin` 에서 새 비밀번호로 로그인 → 방금 예약이 보이는지
- [ ] `/admin/settings` 에서 실제 매장 이름·영업시간·휴무 요일로 수정
- [ ] `/admin/services` 에서 예시 메뉴를 실제 메뉴·가격으로 교체
- [ ] 카카오톡 챗봇에 "예약" → 링크 응답 확인
- [ ] (로그인 켰다면) 카카오/네이버 로그인 → 내 예약 조회 확인

## 7. 운영 팁

- **백업**: `booking.db` 파일과 `photos/` 폴더 두 개가 전부입니다. 주기적으로
  내려받아 두면 어떤 상황에서도 복구할 수 있습니다.
- **리마인드 알림**: 현재는 서버 로그에 기록됩니다(확정/전날 19시/당일 9시).
  알림톡·SMS 실제 발송은 2차 작업으로, `booking/notify.py`의
  `send_notification()` 한 곳만 연동하면 됩니다.
- **요금**: 카카오헤어샵(최대 25%)·네이버(결제 시 최대 2.9%) 같은 예약 수수료가
  없습니다. 서버 호스팅비(월 1만원 안팎)와 Claude API 사용료만 듭니다.
